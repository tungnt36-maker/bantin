Khối ngoại đảo chiều mua ròng với tổng giá trị ròng đạt 378.4 tỷ đồng, tập trung mua KDH, VND.

▪ Kết phiên, VN Index đóng cửa tại 1725.36, giảm 15.37 điểm, tương đương 0.88%. Kết tuần, VN Index giảm 16.26 điểm (-0.93%) so với tuần trước.
